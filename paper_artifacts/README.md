# Curated Symbolic Audit Artifacts

This directory contains small, anonymized derived-result summaries from the symbolic audit.

Raw SWaT data is not included because access is restricted. Distillation arrays, trained checkpoints, full PySR run directories, logs, and model outputs are also not included. The files here are compact CSV summaries intended to support reproducibility checks and paper tables without exposing raw or large local artifacts.

PySR was run unconstrained over all current SWaT input variables. Process context and GeCo references were used only for post-hoc interpretation and labeling; they were not used to restrict the PySR input variables.

Files:

- `symbolic_audit_summary.csv`: curated cross-sensor symbolic audit summary.
- `linear_baseline_summary.csv`: curated OLS/Ridge diagnostic baseline summary.
- `lit101_case_study.csv`: LIT101 subset used for the primary case study.
- `selected_pareto_fronts/`: selected compact Pareto fronts for case-study and proxy-equation examples.

The full artifacts can be regenerated by running the repository scripts with authorized SWaT access and the prepared distillation export directory. Generated run directories remain intentionally ignored by git.
